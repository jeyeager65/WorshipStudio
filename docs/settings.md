# Settings

Settings is organized into a few groups:

## Application

- **This Computer** — this workstation's name (used to label who made a change when resolving a
  [Library Health](/library-health) conflict), and a shortcut to re-run the
  [Getting Started](/getting-started) wizard.
- **Library & Sync** — where your shared library folder lives, a sync health check, and data
  tools (loading sample data or clearing everything — both destructive, used mainly for trying
  the app out).
- **About** — app version, links to the project's source and issue tracker, and diagnostics
  (open the logs folder, or export a diagnostic bundle to share when reporting a problem).

## Appearance & Displays

- **Appearance** — dark mode for the operator interface.
- **Branding** — your church name, logo, and brand colors, used across bulletins, reports, and
  themes.
- **Display Setup** — which connected monitor is the Control Screen and which is the Audience
  Display.
- **Text Sizing** — min/max auto-fit font sizes for scripture and song lyrics, and fixed sizes
  for headers/footers.
- **External Apps** *(Windows only)* — profiles for handing off to another application (like a
  video player) mid-service, including remote next/previous keys.
- **Remote Control** — this computer's pairing info for phones/tablets, and the list of paired
  devices (see [People](/people) for how a device gets paired).

## Content Library

- **Song Collections** — the list of songbooks/collections available on [song](/songs) records.
- **Bible Translations** — KJV is bundled by default; add ESV or an api.bible edition (like NIV)
  with an API key.
- **Canva** — connect this computer to a Canva account for use in the [Slide Library](/slides).

## Service Planning

- **Service Types** — the list of service types offered when creating a
  [service](/services) or setting up a [template](/service-templates)'s defaults.
