# Service Templates

A service template is a reusable starting point for a [service](/services): an order of items
(songs, scripture, sermon, and so on, as placeholders) plus the staffing roles you typically need,
so you're not rebuilding the same structure every week.

![Service Templates library](/screenshots/service-templates.webp)

## Building a template

The editor has three parts:

- **Order** — drag-reorder the content placeholders (Song, Scripture, Sermon, Slide, Media,
  Bulletin Note, or Other), each with its own label.
- **Roles** — the staffing roles this template calls for, grouped by role category (see
  [Roles](/roles)).
- **Defaults** — which service type(s) should automatically use this template when you create a
  new service.

![Service Template editor](/screenshots/service-template-editor.webp)

## Using a template

Pick a template on **Create Service**, or apply one later from Service Plan's **Apply Template**.
Applying a template to a service that's already partly planned is non-destructive — it matches up
already-planned songs, sermon, scripture, and media by kind and label rather than wiping out your
work.

**Duplicate** is the quickest way to build a variation of an existing template — it copies
everything and clears the "default for" setting so the two don't compete.
