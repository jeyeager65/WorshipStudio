# Slides

The Slide Library holds reusable **presentations** — each one an ordered set of slides you can
drop into any [service](/services). Search by label, tag, or the text on the slides themselves.

## Building a slide

The slide editor is a freeform canvas: drag, resize, and rotate elements freely, with snapping
guides and a safe-area toggle to keep content clear of screen edges. You can add:

- **Text**, with an optional outline, shadow, or glow effect
- **Image**, pulled from the [Media Library](/media)
- **Shape**, with its own fill and stroke
- **QR code**
- **Countdown timer**

Backgrounds can be a solid color or a Media Library image/video, with a focal point you can
reposition so the important part of the image stays visible at any screen size.

## Canva designs

If you design in Canva, a slide can be sourced directly from a Canva design — pick one from the
connected Canva account (see [Settings → Canva](/settings)) and Worship Studio keeps it in sync
as the slide's image.

A presentation can hold multiple pages — **Add Slide** appends a new one, and you can drag to
reorder the set.
