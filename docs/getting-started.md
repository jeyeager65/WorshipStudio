# Getting Started

The first time you launch Worship Studio, a setup wizard walks you through everything needed
before you plan your first service. You can skip any step and finish it later from Settings.

![Setup wizard's welcome step](/screenshots/getting-started.webp)

## First question: new library, or joining one?

The wizard opens by asking whether this is the **first** computer at your church to use Worship
Studio, or whether it's **joining** a library another device already set up. Everything after
that depends on the answer, so it's worth getting right.

- **Set up a new library** — nobody has set up Worship Studio yet. You'll name your church,
  choose your defaults, and pick where the library lives.
- **Join an existing library** — another computer already has your songs and services. This
  device only needs to point at the shared folder and name itself.

Joining deliberately keeps the church details, service types and planning defaults already in
that library. A joining device never overwrites them, so setting up a second or third computer
can't quietly clobber choices made on the first.

## What the wizard covers

### Setting up a new library

- **Church Identity** — your church/ministry name and brand colors, used on bulletins, reports,
  and other exported documents.
- **This Device** — a name for this particular computer or tablet, used to label who made a
  change when resolving a [Library Health](/library-health) conflict. It's suggested for you
  based on the device, and you can change it.
- **Display Setup** *(desktop only)* — which connected monitor is the **Control Screen** (what
  you see while running a service) and which is the **Audience Display** (what the congregation
  sees). You can flash a screen with **Identify** to confirm which is which. With only one
  monitor connected, presenting live stays unavailable until a second display is added.
- **Library & Import** — all optional: import songs from OpenSong XML files, choose where your
  shared library folder lives (a Dropbox/OneDrive folder, or a portable folder for a single
  machine), and add a starter set of royalty-free stock background images and themes.
- **Planning Defaults** — your default Bible translation, your primary service type (e.g. Sunday
  Worship — you can add your own), and whether the operator interface starts in dark mode.
- **Ready to Begin** — a summary, plus shortcuts to build your first [Service Template](/service-templates)
  or add your [People and Roles](/people).

### Joining an existing library

Shorter, and in a different order on purpose — the library comes **first**, so every later step
is decided against your real library rather than a guess:

1. **Library & Import** — point at the shared folder (or connect Dropbox/OneDrive on a tablet)
   and let it sync. See [Sync](/sync) for what that means on each kind of device, and
   [Cloud Setup](/cloud-setup) if you're connecting a tablet or a Mac.
2. **Display Setup** *(desktop only)* — displays belong to this machine, not the library, so a
   joining computer still picks its own.
3. **This Device** — name this device.
4. **Ready to Begin**.

Church Identity and Planning Defaults are skipped entirely: those live *in* the library you just
joined, and this device inherits them.

::: tip Tablets and phones
A tablet has no folder to point at, so its Library step connects to Dropbox or OneDrive instead.
That needs a one-time setup on your church's cloud account first — see
[Cloud Setup](/cloud-setup).
:::

## After setup

Everything the wizard sets can be changed later in [Settings](/settings) — display roles, brand
colors, your library folder, this device's name, and so on. If you ever want to run the wizard
again, it's available from Settings → This Computer.

::: tip Where to go next
Most churches set up a [Service Template](/service-templates) next, then move on to building out
the [Song](/songs) and [Slide](/slides) libraries before planning their first real
[Service](/services).
:::
