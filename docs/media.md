# Media

The Media Library holds every image and video you use across the app — as backgrounds in
[Presentation Themes](/themes), as items directly in a [service](/services), or as image
elements in [Slides](/slides). Search by title, filename, description, or tag, and filter by type.

## Importing files

**Browse for images and videos…** stages one or more files at once, with an editable title,
description, and tags per file before you commit the import — a bulk **Tag All** applies tags to
everything added after that point.

Worship Studio nudges you about a couple of things during import, but never blocks you outright:

- **Possible duplicates** are flagged and pre-checked to skip, in case you're re-importing
  something already in the library.
- **Large files** (over the configured size threshold — 50MB by default) are flagged to stay
  **local** to this machine rather than syncing.

## Synced vs. local

Every item has a **Location**: **synced** puts it in your shared library folder so it's available
on every computer, while **local** keeps it on this machine only — useful for large video files
you don't want slowing down sync for the whole team.
