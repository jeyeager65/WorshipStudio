# Presentation Themes

A **theme** pairs a background with text styling, so your songs, scripture, sermon points, and
text slides look consistent without styling each one by hand. This is different from a slide's
own freeform design in the [Slide Library](/slides) — themes style *generated* content.

## What a theme controls

- **Background** — a solid color, an image or video from the [Media Library](/media), or one of
  your brand colors (see [Settings → Branding](/settings)).
- **Text** — font, color, and an effect (none, outline, shadow, or glow), each with its own
  strength and color.

A live preview shows a sample lyric in the actual theme styling as you work, with a full-screen
preview available too.

## Applying themes

Each theme declares which content types it applies to — Songs, Scripture, Sermons, and Text
Slides — either a specific set or all of them. **Use as Default For** makes a theme the automatic
choice for a content type; only one theme can be the default per type, so setting a new default
replaces the old one.

**Duplicate** clones a theme as a starting point for a variation (the clone isn't a default for
anything until you set it).
