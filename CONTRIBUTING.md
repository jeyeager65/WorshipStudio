# Contributing

**Pull requests aren't being accepted before 1.0.** Not for lack of interest — there's enough to
coordinate already, and reviewing changes to a codebase still moving this fast would cost more
than it returns. Please don't spend time on a PR that won't be merged.

**Issues are very welcome**, especially from anyone actually running a service with Worship
Studio: bugs, confusing behaviour, and gaps in the
[help site](https://jeyeager65.github.io/WorshipStudio/) are all useful.
[Open one here](https://github.com/jeyeager65/WorshipStudio/issues).

If you want to build and run it locally anyway — to investigate something before filing an issue,
or just to look around — the [README](README.md) covers requirements, scripts and project layout,
and [notes/](notes/) holds the design notes behind how it works.
